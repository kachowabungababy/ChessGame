## Tuxemon map tiles (Cotton Town)

The overworld map (`maps/cotton_town.json`) is converted directly from the real
`spyder_cotton_town.tmx` map shipped by the [Tuxemon](https://github.com/Tuxemon/Tuxemon)
open-source project, and the tileset images (`tilesets/tuxemon_core_*.png`) are
the project's real `core_*` tilesets, unmodified. Tuxemon's game code is
GPL-3.0 and its art/resources are CC BY-SA 4.0 — see the upstream repo's
`ATTRIBUTIONS.md` and `LICENSE` for full per-asset credits. The conversion
here keeps the tile layout, collision geometry, and sign/door dialogue text
from the original map; it drops Tuxemon's own quest/battle scripting, which
doesn't apply to this project.
